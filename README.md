# Datheon Python Internship Projects

## Project 1: Hangman Word Guessing Game

### Description
A console-based word guessing game developed using Python. The user must guess a secret word within six attempts.

### Features
- Random secret word selection.
- Letter-by-letter guessing.
- Tracks previously guessed letters.
- Prevents duplicate penalty deductions.
- ASCII Hangman graphics.
- Win and Game Over messages.

### Technologies Used
- Python 3
- Random Module
- VS Code

### How to Run
1. Install Python 3.
2. Download the hangman.py file.
3. Open the terminal.
4. Run the command:

python hangman.py

## project 3: Automated File Organizer & Cleanup Utility

Description

Developed a Python-based file organizer that automatically organizes files into different folders based on their extensions.

Technologies Used

- Python 3
- OS Module
- Shutil Module
- Pathlib

Features

- Automatically identifies file extensions.
- Creates category folders such as Images, Documents, Videos, Archives and Code.
- Moves files into their respective folders.
- Handles errors and duplicate filenames.
- Displays an organization summary.

How to Run

1. Open the project in VS Code.
2. Run "organizer.py".
3. Enter the folder path to organize.
4. The program automatically sorts the files.

Output

Successfully organized files into their respective folders.
