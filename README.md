# Datheon Python Internship Projects

## Project 1: Hangman Word Guessing Game

### Description
A console-based word guessing game developed using Python. The user must guess a secret word within six attempts.

### Features
- Random secret word selection.
- Letter-by-letter guessing.
- Tracks previously guessed letters.
- Prevents duplicate penalty deductions.
- ASCII Hangman graphics.
- Win and Game Over messages.

### Technologies Used
- Python 3
- Random Module
- VS Code

### How to Run
1. Install Python 3.
2. Download the hangman.py file.
3. Open the terminal.
4. Run the command:

python hangman.py

## project 3: Automated File Organizer & Cleanup Utility

Description

Developed a Python-based file organizer that automatically organizes files into different folders based on their extensions.

Technologies Used

- Python 3
- OS Module
- Shutil Module
- Pathlib

Features

- Automatically identifies file extensions.
- Creates category folders such as Images, Documents, Videos, Archives and Code.
- Moves files into their respective folders.
- Handles errors and duplicate filenames.
- Displays an organization summary.

How to Run

1. Open the project in VS Code.
2. Run "organizer.py".
3. Enter the folder path to organize.
4. The program automatically sorts the files.

Output

Successfully organized files into their respective folders.

## project 4:Python Chatbot 🤖

Project Description

This is a simple interactive chatbot developed using Python. It communicates with users and provides predefined responses based on their input.

Features

- Responds to greetings like Hello and Hi.
- Answers basic questions.
- Provides help messages.
- Exits when the user types Bye.
- Simple and beginner-friendly.

Technologies Used

- Python 3

How to Run

1. Download or clone the repository.

2. Open the project in VS Code.

3. Run the following command:
   
   "python chat.py"

4. Start chatting with the bot.

Sample Interaction

You: Hello
Bot: Hello! How are you?

You: How are you?
Bot: I am fine. Thank you!

You: Bye
Bot: Goodbye! Have a nice day.

Conclusion

This project helped me understand Python basics, conditional statements, loops, and user input handling.
